Entry for the [P vs NP desk round](https://make.fun/c/desk-pvsnp-20261127) on make.fun.

The whole content of this entry is `DESK.json`:

```json
{"schema": "makefun/desk-entry/v1", "campaign": "pvsnp"}
```

Units are Lean 4 statements in the campaign module `PvsNP.Defs`, proved during the round. A unit is closed by a Lean file proving it — or proving its negated twin. First valid file by receipt takes the unit.
